## Unassigned user stories

These stories describe product needs and are deliberately not assigned to any person:

- As a scientist, I want the observable domain and numerical policy recorded so I can judge whether
  the evidence addresses my scientific question.
- As a developer, I want deterministic offline tests and standalone reproducers so I can investigate
  a translation without credentials or a model call.
- As a research lead, I want candidate facts, recommendations, and approvals separated so technical
  feasibility is not mistaken for scientific priority.
- As a reviewer, I want C, translated code, and an independent reference compared so source-oracle
  disagreements remain visible.
- As an operator, I want resource bounds and explicit infrastructure outcomes so failures are not
  silently counted as passing evidence.
- As a contributor, I want an adapter contract and candidate template so new targets can be proposed
  without embedding their scientific assumptions in the generic core.

Ownership, availability, acceptance criteria, review assignments, and decision rights remain PI
discovery questions.
